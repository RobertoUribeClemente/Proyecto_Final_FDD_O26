# Bitácora — Proyecto Final FDD O26

## 2026-11-19 — Audiomack descartado como fuente de datos

Contactamos al soporte de Audiomack para solicitar acceso a su API. Su respuesta fue:

> "At this time, we don't have a public API and aren't granting access to our internal API."

Es decir, Audiomack **no cuenta con una API pública** y **no está otorgando acceso a su API interna (privada)**, por lo que no podemos usarla como fuente de datos para el proyecto.
